# Final Handoff Checklist

- [ ] Correct native VCarve version confirmed with the shop
- [ ] Five editable CRV jobs open and recalculate in the receiving environment
- [ ] Master nominal geometry and exported DXF revision match
- [ ] Grain, stock, tool definitions and datums documented
- [ ] No accidental reference-layer toolpaths
- [ ] Toolpaths, tabs, starts and retention reviewed for every part
- [ ] Individual VCarve previews and job sheets captured
- [ ] Coupon offsets and measured results retained
- [ ] Full board prototype approval recorded, if physically performed
- [ ] Machine, controller, post and fixture verified before posting
- [ ] Machine code matches the accepted native revision, if released
- [ ] All learning-only assumptions and unperformed steps clearly marked
- [ ] Revision history and rejected test variants included
- [ ] Client shown how to edit, recalculate and identify when retesting is needed
- [ ] Short walkthrough recorded using actual files and actual evidence
