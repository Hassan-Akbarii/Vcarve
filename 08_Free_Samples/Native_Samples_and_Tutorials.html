VCarve native samples and tutorials

Checked 8 November 2026. Start with R01 and R02. All three public starter archives were downloaded and inspected: genuine .crv files are present. They were not opened in VCarve in this environment. Official pages specify version 12 or later; the revision that created each binary was not independently established.

Download the originals directly from Vectric. The third-party designs are not included in the practice pack and must not be presented as your own work. Some archives also contain posted machine code: ignore those files for learning and create your own setup. The optional Python downloader extracts only learning inputs, never machine code.
