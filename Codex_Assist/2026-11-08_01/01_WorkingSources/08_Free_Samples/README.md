# Free Native VCarve Examples

Open Native_Samples_and_Tutorials.html for clickable official downloads and videos. Checked on 8 November 2026: R01 contains Welcome Sign.crv; R02 contains Garden Panel - Toolpaths.crv; R03 contains Backyard BBQ Sign.crv. All three official project pages specify version 12 or later. They were downloaded and archive contents inspected, but not opened in VCarve here.

The original archives remain with Vectric; this pack includes links rather than redistributing their designs. These are learning references, not your portfolio samples. There is no need to sign in for the three verified public downloads at the time of checking. R09 and some other free-library projects require V&Co login.

Optional downloader, using Python 3:

```powershell
py download_official_samples.py
```

It downloads the three archives directly from the verified official URLs and extracts CRV and vector/image learning inputs into a new Official_Downloads folder. It excludes posted G-code and controller files. It does not run any CAD or CNC program. If a direct link changes, use its official page and Download Project Files instead.
